# プラン: 食事記録での小数入力を可能にする

## Linear Issue
- Issue: EDG-721
- URL: https://linear.app/ryosuke-horie/issue/EDG-721/食事記録の時の数値に05などの入力を可能にしたい

## 概要
現状、食事記録の数量入力では整数のみが許可されており、「0.5皿」「0.5個」のような小数を入力できない。これを全ての単位で小数入力を可能にする。

## 実装計画

### 変更ファイル
- `ios/Uchikomi/Features/Meals/Models/MeasurementUnit.swift`

### 変更内容
1. `inputType` プロパティを全ての単位で `.decimal` を返すように変更
2. 使用されなくなった `.integer` ケースを `QuantityInputType` enum から削除

### 技術的な考慮事項
- 変更は単純で、リスクは低い
- `FoodItemEditRow.swift` ですでに条件分岐が存在するため、常に `.decimalPad` キーボードが表示される
- 食事の量は「0.5個」「1.5人前」など小数で表現するケースが一般的であるため、全単位で小数を許可することは合理的

## テスト計画
iOSテストは一時無効化されているため、手動テストで確認する：
1. 食事記録画面を開く
2. 数量入力フィールドをタップ
3. 小数キーボード（.付き）が表示されることを確認
4. 「0.5」「1.5」などの小数が入力できることを確認
