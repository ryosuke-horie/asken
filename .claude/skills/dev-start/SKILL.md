# 開発環境起動スキル

このスキルは開発環境を確実に起動します。

## 重要: 作業ディレクトリの確認

このスキルは `/Users/r-horie/Workspaces/utikomi/main` でのみ自動実行可能です。

他のディレクトリ（worktreeなど）で実行する場合は、必ずAskUserQuestionツールで確認を取ってください：

```
現在の作業ディレクトリは /Users/r-horie/.agi-tools/worktrees/sub-XXX です。
開発環境を起動してもよろしいですか？
```

## 事前チェック（必須）

開発環境を起動する前に、以下のチェックを必ず実行してください：

### 1. ポートの確認

バックエンドサーバー（8080）が使用中でないか確認：

```bash
lsof -i :8080
```

ポートが使用中の場合：
- 既存プロセスを停止するか、ユーザーに確認を取る
- 別の開発環境が動作中の可能性がある

### 2. Xcodeプロセスの確認

Xcodeでビルド/テスト中だと開発環境がクラッシュする可能性があるため確認：

```bash
pgrep -l Xcode
pgrep -l xcodebuild
```

Xcodeが動作中の場合：
- ビルドやテスト中は開発環境の起動を避ける
- ユーザーに「Xcodeでビルド/テスト中のようです。開発環境を起動してもよいですか？」と確認

## 起動手順

事前チェックが完了したら、バックエンドサーバーを起動：

```bash
task run
```

バックエンドサーバーをバックグラウンドで起動します。
ポート8080でリッスンします。

## 実行フロー

1. 作業ディレクトリを確認（mainディレクトリ以外なら確認を取る）
2. ポート8080が空いているか確認
3. Xcodeプロセスを確認（動作中なら警告/確認）
4. `task run` をバックグラウンドで実行
5. サーバーが起動したことを確認

## 確認ポイント

- バックエンド: `curl http://localhost:8080/health` でヘルスチェック

## 注意事項

- Xcodeでのビルド/テスト中は開発環境の起動を避ける
- worktreeで作業中は、mainの開発環境と競合しないよう注意
