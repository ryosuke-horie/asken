# リファクタリングクリーン

テスト検証付きでデッドコードを安全に特定・削除:

1. デッドコード分析ツールを実行:
   - knip: 未使用エクスポートとファイルを検出
   - depcheck: 未使用依存関係を検出
   - ts-prune: 未使用TypeScriptエクスポートを検出

2. `.reports/dead-code-analysis.md`に包括的なレポートを生成

3. 発見事項を重大度で分類:
   - SAFE: テストファイル、未使用ユーティリティ
   - CAUTION: APIルート、コンポーネント
   - DANGER: 設定ファイル、メインエントリポイント

4. 安全な削除のみを提案

5. 各削除前に:
   - 全テストスイートを実行
   - テストが通ることを確認
   - 変更を適用
   - テストを再実行
   - テストが失敗した場合はロールバック

6. クリーンアップした項目のサマリーを表示

テストを実行せずにコードを削除しないでください。
