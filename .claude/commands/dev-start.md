# 開発環境起動コマンド

このコマンドは開発環境を確実に起動します。

## 起動手順

以下の順序で起動してください：

### 1. データベースの起動

```bash
task db-up
```

PostgreSQLコンテナを起動します。起動完了を確認してから次に進みます。

### 2. テストデータの投入（任意）

DBが初期化された場合や、テストデータが必要な場合：

```bash
task db-seed
```

### 3. バックエンドサーバーの起動

```bash
task run
```

バックエンドサーバーをバックグラウンドまたは別ターミナルで起動します。
ポート8080でリッスンします。

### 4. フロントエンドサーバーの起動

```bash
task frontend:dev
```

フロントエンド開発サーバーをバックグラウンドまたは別ターミナルで起動します。
ポート3000でリッスンします。

## 実行方法

このスキルが呼び出されたら、以下を実行してください：

1. `task db-up` を実行し、DBが起動するまで待機
2. ユーザーにテストデータ投入が必要か確認
3. `task run` をバックグラウンドで実行
4. `task frontend:dev` をバックグラウンドで実行
5. 両サーバーが起動したことを確認

## 確認ポイント

- DB: `docker ps` でPostgreSQLコンテナが起動していること
- バックエンド: `curl http://localhost:8080/health` でヘルスチェック
- フロントエンド: `curl http://localhost:3000` でアクセス可能

## 開発終了時

開発終了時は以下を実行：

```bash
# サーバープロセスを停止（Ctrl+C または kill）
task db-down
```

## 注意事項

- バックエンドとフロントエンドはそれぞれ別プロセスで起動する必要がある
- tmuxを使用すると複数のサーバーを管理しやすい
- `task db-seed`は`backend/.env`の環境変数を読み込む
