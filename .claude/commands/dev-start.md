# 開発環境起動コマンド

このコマンドは開発環境を確実に起動します。

## 重要: 作業ディレクトリの確認

このスキルは `/Users/r-horie/Workspaces/utikomi/main` でのみ自動実行可能です。

他のディレクトリ（worktreeなど）で実行する場合は、必ずAskUserQuestionツールで確認を取ってください：

```
現在の作業ディレクトリは /Users/r-horie/.agi-tools/worktrees/sub-XXX です。
開発環境を起動してもよろしいですか？
```

## 事前チェック（必須）

開発環境を起動する前に、以下のチェックを必ず実行してください：

### 1. ポートの確認

バックエンドサーバー（8080）とPostgreSQL（5432）が使用中でないか確認：

```bash
lsof -i :8080 -i :5432
```

ポートが使用中の場合：
- 既存プロセスを停止するか、ユーザーに確認を取る
- 別の開発環境が動作中の可能性がある

### 2. Dockerの状態確認

```bash
docker ps -a
docker system df
```

確認ポイント：
- Dockerデーモンが起動しているか
- 既存のコンテナが動作中でないか
- ディスク容量に余裕があるか（90%以上なら警告）

### 3. Xcodeプロセスの確認

Xcodeでビルド/テスト中だと開発環境がクラッシュする可能性があるため確認：

```bash
pgrep -l Xcode
pgrep -l xcodebuild
```

Xcodeが動作中の場合：
- ビルドやテスト中は開発環境の起動を避ける
- ユーザーに「Xcodeでビルド/テスト中のようです。開発環境を起動してもよいですか？」と確認

## 起動手順

事前チェックが完了したら、以下の順序で起動：

### 1. データベースの起動

```bash
task db-up
```

PostgreSQLコンテナを起動します。起動完了を確認してから次に進みます。

### 2. データベースの初期化とテストデータの投入

毎回DBを初期化してSeedを投入します：

```bash
task db-clean
task db-seed
```

### 3. バックエンドサーバーの起動

```bash
task run
```

バックエンドサーバーをバックグラウンドで起動します。
ポート8080でリッスンします。

## 実行フロー

1. 作業ディレクトリを確認（mainディレクトリ以外なら確認を取る）
2. ポート8080, 5432が空いているか確認
3. Dockerの状態を確認
4. Xcodeプロセスを確認（動作中なら警告/確認）
5. `task db-up` を実行し、DBが起動するまで待機
6. `task db-clean` でDBを初期化
7. `task db-seed` でテストデータを投入
8. `task run` をバックグラウンドで実行
9. サーバーが起動したことを確認

## 確認ポイント

- DB: `docker ps` でPostgreSQLコンテナが起動していること
- バックエンド: `curl http://localhost:8080/health` でヘルスチェック

## 開発終了時

開発終了時は以下を実行：

```bash
# サーバープロセスを停止（Ctrl+C または kill）
task db-down
```

## 注意事項

- `task db-seed`は`backend/.env`の環境変数を読み込む
- Xcodeでのビルド/テスト中は開発環境の起動を避ける
- worktreeで作業中は、mainの開発環境と競合しないよう注意
