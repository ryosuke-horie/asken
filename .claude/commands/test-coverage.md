# テストカバレッジ

テストカバレッジを分析し、不足しているテストを生成:

1. カバレッジ付きでテスト実行: `npm test -- --coverage`

2. カバレッジレポートを分析（coverage/coverage-summary.json）

3. 80%カバレッジ閾値を下回るファイルを特定

4. 各カバレッジ不足ファイルに対して:
   - テストされていないコードパスを分析
   - 関数のユニットテストを生成
   - APIの統合テストを生成
   - 重要フローのE2Eテストを生成

5. 新しいテストが通ることを確認

6. 前後のカバレッジ指標を表示

7. プロジェクト全体で80%以上のカバレッジを確保

フォーカス:
- ハッピーパスシナリオ
- エラーハンドリング
- エッジケース（null、undefined、空）
- 境界条件

## プロジェクト固有のカバレッジ要件

100%カバレッジ必須:
- 栄養素計算ロジック
- Gemini API連携

80%以上カバレッジ:
- APIエンドポイント
- ユーティリティ関数

60%以上カバレッジ:
- UIコンポーネント
