# ビルド修正

TypeScriptとビルドエラーを段階的に修正します:

1. ビルド実行: `npm run build`

2. エラー出力を解析:
   - ファイル別にグループ化
   - 重大度順にソート

3. 各エラーに対して:
   - エラーコンテキストを表示（前後5行）
   - 問題を説明
   - 修正を提案
   - 修正を適用
   - ビルドを再実行
   - エラーが解決されたことを確認

4. 以下の場合は停止:
   - 修正が新しいエラーを発生させた
   - 同じエラーが3回試行しても解消されない
   - ユーザーが一時停止を要求

5. サマリーを表示:
   - 修正したエラー
   - 残っているエラー
   - 新たに発生したエラー

安全のために一度に1つのエラーを修正してください。
