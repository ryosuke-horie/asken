# E2Eコマンド

このコマンドはe2e-runnerエージェントを呼び出し、XCUITestを使用したiOSアプリのE2Eテストの生成、保守、実行を行います。

## このコマンドの機能

1. テストジャーニー生成 - ユーザーフローのXCUITestテストを作成
2. E2Eテスト実行 - iOSシミュレータでテストを実行
3. アーティファクトキャプチャ - 失敗時のスクリーンショット
4. 結果レポート - テスト結果の表示
5. フレークなテストの特定 - 不安定なテストを隔離

## 使用タイミング

`/e2e`を使用する場合:
- 重要なユーザージャーニーのテスト（画像アップロード、栄養素表示）
- 複数ステップのフローがE2Eで動作することを確認
- UIインタラクションとナビゲーションのテスト
- iOSアプリとバックエンドの統合検証
- 本番デプロイの準備

## 動作方法

e2e-runnerエージェントは:

1. ユーザーフローを分析しテストシナリオを特定
2. Accessibility Identifierを使用してXCUITestテストを生成
3. iOSシミュレータでテストを実行
4. 失敗をスクリーンショットでキャプチャ
5. 結果を含むレポートを生成
6. フレークなテストを特定し修正を推奨

## プロジェクト固有の重要フロー

このプロジェクトでは以下のE2Eテストを優先:

CRITICAL（常にパスが必要）:
1. 食事画像をアップロードできる
2. 栄養素が正しく表示される
3. 食品検索が動作する
4. 食事履歴が表示される

IMPORTANT:
1. エラー時の適切な表示
2. ログイン/認証フロー

## クイックコマンド

```bash
# iOSテストを実行
task ios:test

# カバレッジ計測付きテスト
task ios:test:coverage

# iOSリント
task ios:lint
```

## ベストプラクティス

推奨:
- Accessibility Identifierをセレクタに使用
- waitForExistenceで非同期待機
- 重要なユーザージャーニーをE2Eでテスト
- mainにマージする前にテストを実行
- テスト失敗時にスクリーンショットを確認

非推奨:
- sleep()による固定待機（waitForExistenceを使用）
- ハードコードされた座標を使用
- 実装詳細をテスト
- フレークなテストを無視
- 全エッジケースをE2Eでテスト（ユニットテストを使用）
