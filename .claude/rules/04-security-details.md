# セキュリティガイドライン詳細

## コミット前のセキュリティチェック

コミット前に必ず確認:

- [ ] ハードコードされたシークレットがない（APIキー、パスワード、トークン）
- [ ] 全てのユーザー入力が検証されている
- [ ] XSS対策（HTMLサニタイズ）
- [ ] エラーメッセージが機密データを漏洩しない

## シークレット管理

```typescript
// NG: ハードコードされたシークレット
const apiKey = "AIzaSy-xxxxx"

// OK: 環境変数から取得し検証
const apiKey = process.env.GEMINI_API_KEY
if (!apiKey) {
  throw new Error('GEMINI_API_KEY not configured')
}
```

## セキュリティ問題発見時の対応

セキュリティ問題を発見した場合:

1. 作業を即座に停止
2. security-reviewerエージェントを使用
3. CRITICALな問題は続行前に修正
4. 漏洩したシークレットがあればローテーション
5. 類似の問題がないかコードベース全体をレビュー

## プロジェクト固有の注意点

### Gemini API連携

- APIキーがサーバーサイドのみで使用されていることを確認
- タイムアウト設定の確認
- レスポンスの適切なバリデーション

### Firestore

- 機密データのログ出力禁止
