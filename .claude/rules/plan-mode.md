# Plan Modeルール

## プラン保存の必須事項

Plan modeでプランを作成する際は、以下のルールを必ず守ること。

### 1. 保存先

プランは `docs/plan` ディレクトリに保存する（settings.jsonで設定済み）。

### 2. ファイル命名規則

```
edg-{LinearのIssue番号}-{簡潔な説明}.md

例:
- edg-305-image-upload.md
- edg-421-nutrition-calculation.md
- edg-512-gemini-integration.md
```

### 3. プランファイルの必須内容

プランファイルには以下を必ず含めること:

```markdown
# プラン: {タイトル}

## Linear Issue
- Issue: EDG-{番号}
- URL: https://linear.app/ryosuke-horie/issue/EDG-{番号}

## 概要
{このプランで達成すること}

## 実装計画
1. {ステップ1}
2. {ステップ2}
...

## 技術的な考慮事項
{アーキテクチャ、依存関係、リスクなど}

## テスト計画
{テスト方針}
```

### 4. プラン作成のタイミング

以下の場合にプランを作成し、保存すること:

- 新機能の実装開始前
- 複雑なリファクタリング開始前
- アーキテクチャに影響する変更前
- ユーザーがPlan modeでの計画を依頼した場合

### 5. 注意事項

- LinearのIssue番号がない場合は、先にLinearでIssueを作成すること
- プランは必ずファイルとして残すこと（口頭での説明だけで終わらせない）
- プラン作成後、実装前にユーザーの確認を待つこと
